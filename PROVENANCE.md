# Provenance

This repository implements `spec-plateforme-vote.md`, itself an implementation
restatement of the functional requirements written for the Commune de
Sainte-Marie-du-Mont (Isère).

Copyright in this code, to the extent any subsists, is Romain VINCENT's; the
commune is the client the software was written for, not its author.

The code was produced with the assistance of a large language model, working
from that specification, under human review. This file records how the code was
made; the licence stands on its own and makes no claim about it. Asserting in a
repository that code bears no copyright states a jurisdiction-dependent legal
conclusion a reuser cannot verify, whereas the permissive grant in
[LICENSE](LICENSE) is effective whether or not rights subsist.

The independent verifier under `verifier/` was written from the specification
rather than from the Python implementation, and shares no code with it — a
property the language boundary enforces structurally (§14).
