{% translate "Aide" %}

{% translate "Les réponses aux questions les plus courantes sur cette plateforme de consultation citoyenne." %}

{% translate "Qu'est-ce que ce site ?" %}

{% translate "Ce site permet à la commune de consulter ses habitants sur des sujets locaux. Chaque consultation est présentée avec les propositions soumises, un calendrier et, une fois close, son résultat." %}

{% translate "Le résultat éclaire la décision du conseil municipal ; il ne la remplace pas." %}

{% translate "Comment participer à une consultation ?" %}

{% translate "Depuis la page d'une consultation ouverte, vous vous inscrivez avec votre nom, vos coordonnées et une adresse électronique. Cette inscription est vérifiée par rapport à la liste électorale de la commune : elle confirme que vous avez le droit de participer, sans que votre vote ne soit jamais relié à votre identité." %}

{% translate "Vous recevez ensuite un courriel contenant un lien personnel. Ce lien ouvre votre bulletin, sur lequel vous classez les propositions selon vos préférences." %}

{% translate "Je ne reçois pas le courriel de vote" %}

{% translate "Vérifiez d'abord votre dossier de courriers indésirables. Si le courriel n'arrive toujours pas, assurez-vous d'avoir utilisé l'adresse indiquée à votre inscription ; en cas de doute, recommencez l'inscription avec la bonne adresse." %}

{% translate "Si votre nom n'a pas été retrouvé sur la liste électorale, votre inscription est mise en attente le temps qu'un agent de la mairie l'examine ; vous serez informé par courriel dès qu'une décision est prise." %}

{% translate "Puis-je voter autrement qu'en ligne ?" %}

{% translate "Un bulletin papier peut être déposé en mairie ; il est saisi par un membre du conseil municipal dans la même consultation." %}

{% translate "Puis-je modifier mon vote après l'avoir envoyé ?" %}

{% translate "Cela dépend de la consultation : certaines autorisent le remplacement du bulletin tant que le vote en ligne reste ouvert, en revotant depuis le même lien reçu par courriel ; d'autres non. Le bulletin le plus récent est le seul compté ; les précédents sont conservés mais ne sont plus décomptés." %}

{% translate "Comment fonctionne le classement des propositions ?" %}

{% translate "Sur votre bulletin, vous classez les propositions par ordre de préférence plutôt que de n'en choisir qu'une seule. Selon la consultation, un classement complet peut être exigé ou non, et deux propositions peuvent être placées à égalité. La méthode de dépouillement utilisée est rappelée sur la page de résultat de chaque consultation." %}

{% translate "Comment savoir si mon vote a été pris en compte ?" %}

{% translate "Au moment de voter, un code de suivi vous est remis. Une fois la consultation close et le résultat publié, ce code figure dans la liste des bulletins retenus, publiée avec le résultat : vous y retrouvez le vôtre pour confirmer qu'il a bien été enregistré tel que vous l'avez exprimé." %}

{% translate "Que deviennent mes données personnelles ?" %}

{% translate "Les informations transmises à l'inscription servent uniquement à vérifier votre droit de participer et à vous envoyer votre lien de vote ; elles sont supprimées deux mois après la clôture de la consultation. Votre bulletin n'est relié à votre identité par aucune donnée conservée : la plateforme sait que vous avez voté, jamais ce que vous avez voté." %}
